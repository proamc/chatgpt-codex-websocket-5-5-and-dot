# 在新 Mac 上恢复这套使用方式

## 1. 准备原版应用和 Clash

从官方渠道安装原版 ChatGPT/Codex、Clash Verge Rev，登录自己的账号。在 Clash 中导入自己的订阅并选择可用节点。

| 设置 | 建议恢复值 |
| --- | --- |
| 模式 | 规则模式；核对实际目标命中的规则和出口 |
| 系统代理 | 开启 |
| TUN / 虚拟网卡 | 关闭 |
| HTTP / Mixed 端口 | 以本机为准，常见为 7897 |
| 允许局域网 | 本机使用可保持关闭 |
| Clash 登录启动 | 可开启，重启后仍检查代理状态 |

先验证网页能用。若这一层失败，先检查节点与分流。先不为这次恢复额外修改 DNS、Tailscale 或 TUN 路由。

参考：[Clash Verge 快速入门](https://www.clashverge.dev/guide/quickstart.html)。

## 2. 安装无终端入口

从本仓库 Releases 下载启动应用，放在 `~/Applications`。没有这个文件夹就在个人主目录新建 `Applications`。把入口拖进程序坞，保留原版应用的安装位置。

先保存任务并完整退出原版应用，再点新入口。首次填写端口及原版 `.app` 路径。可用 Option 启动重新配置。此步骤不自动安装 Clash、不导入订阅、不替你登录，也不修改模型配置。

## 3. 按需要添加模型 HTTPS 配置

如果需要避免模型 Responses WebSocket，按 [单独的说明](model-https.zh-CN.md) 备份、合并配置，然后重启并新建本地 Codex 聊天。

如果你只需要补上 dot 的显式代理，也可以先只用启动器，独立验证 dot 是否恢复。

## 4. 重新连接 dot

在新电脑的 ChatGPT 应用中打开 dot 资料页，在 Computers / 电脑下选择本机并允许访问。保持电脑在线、应用打开。当前官方说明一个 dot 只能同时连接一台个人电脑，迁移时确认自己选择的是新电脑。

参考：[OpenAI：连接电脑与应用](https://learn.chatgpt.com/docs/dots/computers-and-apps)。

可复制这个只读测试指令：

> 请在我刚连接的这台 Mac 上查询 macOS 版本和构建号，并查询 uname -s。报告实际工具执行结果，只做只读查询，不读写我的个人文件，不使用云端电脑代替。

复制到自己的笔记中登记。未做的项目保留“未测”。

端口在监听、浏览器能打开、电脑显示在线，各自只证明一层。不能用其中一个代替另外几个。

## 迁移时带走什么

带走本项目或发布包、自己的订阅获取方式、必要的配置片段即可。重新登录应用并重新授权本机。

不要把整份旧电脑 `.codex`、认证文件、Cookie、完整日志、订阅链接或带个人路径的私有恢复报告发到公共仓库。
